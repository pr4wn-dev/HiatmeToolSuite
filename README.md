# Hiatme Tool Suite v3

Windows desktop app for Modivcare dispatch: **Schedule Builder**, templates, maps (OSRM routes), Supey AI assist, billing, and related tools.

Scheduling **BUILD** / geocode / route solving runs on the **[AIagent](https://github.com/pr4wn-dev/AIagent)** panel in the office — not on each desk GPU.

## Repositories

| Repo | Role |
|------|------|
| **HiatmeToolSuite** (this) | Dispatch UI (C# / .NET Framework 4.8) |
| **[AIagent](https://github.com/pr4wn-dev/AIagent)** | Office server: panel `:8787`, Ollama, OSRM, BUILD APIs |

Clone both on the **server** (AIagent only) and on **each desk** (Tool Suite; point config at the server).

## New office server

1. **AI host** — follow [AIagent: DEPLOY-NEW-SERVER](https://github.com/pr4wn-dev/AIagent/blob/main/docs/DEPLOY-NEW-SERVER.md) or run `bootstrap-new-server.ps1`.
2. **Desks** — [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) (`setup-desk.ps1`).

## Build Tool Suite from source

Requires **Visual Studio 2022** (or Build Tools) with .NET desktop workload.

```powershell
cd "Hiatme Tool Suite v3\Hiatme Tool Suite v3"
# MSBuild path varies; example:
& "${env:ProgramFiles(x86)}\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe" `
  "Hiatme Tool Suite v3.csproj" /p:Configuration=Debug
```

Output: `bin\Debug\Hiatme Tool Suite v3.exe`

Release packaging: `Hiatme Tool Suite v3\release\package.ps1`
