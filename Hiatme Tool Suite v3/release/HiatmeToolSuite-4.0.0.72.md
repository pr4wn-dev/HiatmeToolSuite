# Hiatme Tool Suite 4.0.0.72

**Schedule Builder LOAD uses the published server file, not OneDrive.** Opening a
day used to open the Desktop workbook. OneDrive kept serving Remie's old copy, so
Cherie saw yesterday. LOAD now pulls the published file into a local cache and
opens that.

**SAVE uploads the bytes just written.** After a write, OneDrive could put the old
Desktop file back. The app now uploads the verified copy, not whatever OneDrive
left on the Desktop.
