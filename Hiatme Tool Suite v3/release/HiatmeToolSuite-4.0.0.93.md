# Hiatme Tool Suite 4.0.0.93

Schedule Builder saves now copy straight to your PC and Desktop even when the panel server is down. If you reopen or click LOAD before the server is back, it opens your saved local copy instead of an older schedule, and pushes your queued save up automatically as soon as the server comes back online.

While a schedule is open, Schedule Builder now quietly checks Modivcare in the background every few minutes (shared across all desks so Modivcare only gets one check at a time). When new trips come in, they drop straight into Reserves with the top banner and a live toast on the other desks.
