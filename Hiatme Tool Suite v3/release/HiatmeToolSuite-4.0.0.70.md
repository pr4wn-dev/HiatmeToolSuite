# Hiatme Tool Suite 4.0.0.70

**Playbook questions in the corner are readable now.** A question arrives as a whole
sentence, and toast lines could only break between pieces of text, so the sentence ran
off the edge of the card and was cut off mid-word. Long text now wraps by word, question
toasts get more room than event toasts, and the client's name is no longer printed twice
when the chip above the question already shows it.
