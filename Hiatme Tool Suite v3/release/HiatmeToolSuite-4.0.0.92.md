# Hiatme Tool Suite 4.0.0.92

The billing pill drops a trip once WellRyde says Billed. It checks again during the day, so a morning count does not stay up after those trips are billed.

On the Thursday a pay period ends, today's finished trips show until 4:30 PM. That is the deadline to bill them. After 4:30, today drops off. The next pay Thursday is October 22. Any other day, today stays off the pill.
